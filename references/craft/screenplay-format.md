# 剧本格式（唯一业务标准 default-cn）

正文必须严格使用以下结构，不得使用 Markdown 粗体、代码围栏或额外说明：

```text
第1集：集标题

1-1 地点 时间 内/外
人物：角色A、角色B

△动作行。
角色A（表演提示）：台词。
角色A（OS）：内心/画外音。
```

规则：

- 分集标识：`EP001` 或 `第N集`（阿拉伯数字），标题跟在冒号后；
- 每个场景必须有场次标题 `集-场 地点 时间 内/外`（时间词：日/夜/晨/黄昏/傍晚/白天/夜晚/黎明/午夜）；
- 动作行以 `△` 开头；
- 台词：`角色（表演提示）：台词`；OS/VO：`角色（OS）：台词`、`角色（VO）：台词`；
- 人物列表用顿号分隔；
- 闪回/蒙太奇用 `△闪回：...` / `△蒙太奇：...` 动作行表达，不要用 `【】` 或 Markdown 引用；
- 输出开头和结尾不要 ``` 代码围栏，不要输出审核说明、字数统计或 Craft 名称。
