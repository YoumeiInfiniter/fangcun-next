# 剧本格式

## 展示格式与传输格式分离

- 业务剧本格式：编剧和公司阅读的正文（唯一标准）；
- 内部状态格式：JSON（references/schemas/）；
- 传输格式：按平台包装（如旧版 `<scriptItem>`），由 Renderer 处理，Writer 不负责。

## 默认业务格式（default-cn）

```text
第1集：系统绑错人

1-1 谢家书房 夜 内
人物：叶聆、谢淮舟、996

△谢淮舟将离婚协议放到叶聆面前。
谢淮舟（冷淡）：录完节目，我们离婚。
叶聆（OS）：我的三亿呢？

△半空弹出一只发光小团。
996：炮灰自救系统996号为您服务！
```

规则：

- 分集标识：`EP001` 或 `第N集`，数字用阿拉伯数字；标题写在标识后（`：` 分隔）；
- 场次标题：`集-场 地点 时间 内/外`；
- 时间词：日/夜/晨/清晨/黄昏/傍晚/白天/夜晚/黎明/午夜；
- 人物列表：`人物：A、B、C`，用顿号分隔（可省略）；
- 动作行以 `△` 开头；
- 台词：`角色（表演提示）：台词`；OS：`角色（OS）：台词`；VO：`角色（VO）：台词`；
- 同一时间、同一地点、同一内外关系的连续戏合并为一场；大场景用动作行标注子区域；
- 不使用 Markdown 粗体作为业务格式；不在正文输出审核说明、字数统计或 Craft 注释。

## 旧 XML 兼容（可选）

```xml
<scriptItem name="EP001">
业务剧本正文
</scriptItem>
```

XML 由 `format_renderer` 包装，标签外禁止额外注释；Writer 不直接维护 XML。

## 确定性校验

`scripts/script_validator.py` 检查：分集标题、场次标题、人物列表、动作行、台词行、OS/VO、XML 完整性（仅兼容模式）、标签外内容、空场次、无法解析行、连续重复场 key。格式校验不评价台词质量和剧情逻辑。
