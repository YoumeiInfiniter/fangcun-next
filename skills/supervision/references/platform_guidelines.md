## 七大类过审红线

### 一、内容题材合规及分级备案
- 重点微短剧（总投资 ≥300万 / 特殊题材）：广电总局统一备案
- 普通微短剧（100-300万）：省级广电备案
- 其他微短剧（<100万）：平台自行备案

## 内容质量红线

| 红线 | 说明 |
|------|------|
| 剧名/简介/封面与内容不一致 | 信息必须一致 |
| 剧集缺失 | 审核下线的集需及时修复 |
| 剧集乱序 | 顺序正确 |
| 断更烂尾 | 完整结局 |
| 剧情不连贯 | 逻辑自洽 |
| 非短剧体裁 | 不能是短视频合集/Vlog/音乐视频拼接 |
| 音画质缺陷 | 画幅异常、音画不同步、字幕缺失错乱 |
| 其他平台水印/备案号 | 清除外平台标记 |
| 非官方广告/引流/二维码 | 清除无关推广 |
| 封面低俗/恐怖 | 清除不良观感元素 |

## 漫剧特别注意事项（动画版）

- AI工具使用需注意内容质量、画风一致性、剧情连贯性
- 人物造型避免怪异、扭曲、恐怖
- 诅咒/巫术/蛊术超自然手段禁止
- 画面内容可使用平台风控工具进行评估
