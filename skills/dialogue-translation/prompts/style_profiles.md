# 台词风格 Profile

## default

自然影视口语。简洁、顺口、适合演员直接说。

## theatrical

话剧风格。更有仪式感、情绪张力更强，但不能过度文绉绉。

## gangster

黑帮口语。短句、压迫感、带威胁和街头语气；避免无意义脏话堆砌。

## classical_polite

斯文古典。更克制、更讲究措辞，适合贵族、旧时代、知识分子角色。

## localized_slang

本土口语。按目标地区做自然化表达，优先可听懂、可表演。

## comedy

喜剧口吻。保留包袱和节奏，必要时本土化笑点。

## noir

黑色电影风格。冷峻、隐喻、压抑，适合悬疑犯罪。
