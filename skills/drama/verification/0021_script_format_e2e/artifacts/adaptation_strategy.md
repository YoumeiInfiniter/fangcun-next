# 《山海传媒》改编指引（验证用）

## 核心改编方向

- 类型：都市奇幻喜剧。
- 开场方式：第一集必须是抓包现场，不开大会、不挂横幅、不解释世界观。
- 主冲突：妖怪本能与现代城市规则冲突；罚单、投诉、封号、消防、身份核验都是现实压力。
- 喜剧方式：能力不是炫技，而是在人类社会造成麻烦。

## 角色功能

- 张沫：破产 MCN 老板，负责把所有妖怪按进现代规则里。骂人要具体、现实、带财务压力。
- 九尾狐：性别/身份流动，制造身份核验和诈骗误会。
- 毕方：高温和火星造成消防隐患。
- 夫诸：紧张积水，造成办公事故。
- 鸣蛇：高频声波触发警报和玻璃破裂。
- 蛊雕：食人本能被现代刑事风险压住。
- 狼族三胞胎：服从性差，像没牵绳的大型犬。

## 格式硬规则

- 场次标题必须为：`集-场　地点/场景　时间　内/外`。
- 正确示例：`1-1　怪力乱神管理局 大会场　日　内`。
- 禁止：`【第一集第一场】`。
- 禁止：编号单独成行后再写 `场：地点-时间-内外`。
