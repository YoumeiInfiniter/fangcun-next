# 《山海传媒》故事大纲（验证用）

## 一句话梗概

破产老板张沫接手一群无法适应现代社会的山海经妖怪员工，被迫把他们训练成能在人类世界合法营业的短视频团队。

## 第一幕：接手罚单公司

张沫以为自己捡漏租到便宜办公室，却发现所谓资产是一群妖怪员工和一堆罚单。她在大会场抓包众妖，逐个指出他们的能力在人类社会造成的麻烦。

## 第二幕：把本能变成业务

张沫发现妖怪能力虽然危险，但如果被规则约束，也可能变成短视频内容的差异化卖点。她决定先建立公司纪律：不能吓人、不能纵火、不能吃人、不能拆家。

## 第三幕：第一次直播危机

众妖第一次直播前状况百出。九尾狐换脸引发账号实名风险，毕方差点点燃补光灯，鸣蛇让麦克风爆音，狼族三胞胎追着猫冲出镜头。张沫被迫临场救场，却意外让直播数据暴涨。

## 付费钩子

第 2 集末，平台风控电话打来：山海传媒账号疑似非人类运营，要求明天接受线下核验。
