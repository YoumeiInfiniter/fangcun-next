# 《山海传媒》测试原文片段（版权安全原创）

> 用途：Fangcun 0021「剧本场次格式」端到端回归验证。本文为验证专用原创片段，不来自外部小说。

雨停在下午四点二十七分。

张沫站在“怪力乱神管理局”褪色的铜牌下，手里攥着一沓罚单。铜牌旁边，新贴的“山海传媒有限公司”招牌歪了一角，像一张没睡醒的脸。她原本只想盘下一个便宜办公室，没想到前房东跑路前，把七个妖怪员工连同三十六张行政处罚单一并塞给了她。

大会场里一片狼藉。九尾狐坐在最前排，临时身份证上性别一栏被涂改了三次；毕方缩在灭火器旁边，羽毛尖还冒着细小火星；夫诸站在饮水机边，脚下已经积出一圈水；鸣蛇只是不耐烦地哼了一声，天花板上的灯管便嗡嗡作响；蛊雕盯着外卖小哥留下的头盔，露出认真研究菜单的表情；狼族三胞胎郎日、郎月、郎星蹲在角落，嘴里还叼着从楼下宠物店抢来的狗绳。

张沫把罚单拍在会议桌上。

“从现在开始，”她说，“谁再把本能当才艺，谁就自己去交罚款。”

九尾狐抬头，半张脸是清秀少年，半张脸却又像刚换上的女明星滤镜。他委屈地说，自己只是帮客户看清真爱。张沫指着他的临时身份证，问他今天到底用哪张脸进地铁。毕方想解释，刚张嘴就喷出一粒火星，烧穿了投诉记录的一角。夫诸一紧张，会议桌下开始下雨。鸣蛇憋着笑，玻璃杯出现细细裂纹。蛊雕举手，说他可以负责清理现场，最好从外卖小哥开始。狼族三胞胎闻见楼下猫粮味，尾巴同时竖了起来。

张沫闭上眼，深吸一口气。

她终于明白，这家公司不是缺钱，是缺一套能让妖怪活在人类规则里的办法。而她今天要做的第一件事，不是开会，不是换招牌，更不是发表热血宣言。她要把这群会走路的罚单，一个个按在人类社会的桌面上，逼他们学会装成人。
