# 短剧写作方法论（agent 参考）

本文件是写作技法参考，不是格式约束。agent 在需要时加载，不写进 script.md。

## 三大情绪要点（每集必含至少1个）

| 要点 | 定义 | 作用 |
|------|------|------|
| 爆点 | 令人震惊的事件 | 快速入戏 |
| 虐点 | 让人心痛的事件 | 情感代入 |
| 爽点 | 让人兴奋的高光时刻 | 满足情绪需求 |

- 每集500-800字须覆盖至少一个
- 小情绪累积成大爆发，不可一次宣泄完

## 爽点公式

爽点 = 装 + 打脸 + 震惊 + 收获

## 情绪铺设技巧

- **先压后爆**：先打压主角，关键集反击。压得越狠反弹越爽
- **信息差**：观众知道角色不知道 → 期待感
- **拉扯**：每分钟一次"危机→解除→再危机"

## 开篇规则

- 第1行就入危机，无缓冲期
- 前3集必须见效
- 每集至少1个反转
- 第1集设定主角大目标

## 台词原则

- 精准戳点：针对角色软肋设计
- 贴合性格：遮挡名字仍能判断说话人
- 口语化：禁半文半白
- 单句 ≤20字

## 人物塑造

- 先立标签（1-2个关键词）
- 行动契合人设
- 设定记忆点（口音/动作/怪癖）
- 弧光：初始→变故→转变→最终

## 高频情绪模板

**打压-反击**：嘲讽→变本加厉→亮身份→道歉（逆袭类）
**误会-解开**：造谣→冷战→发现真相→撒糖（甜宠类）
**危机-救赎**：难题→求助无门→贵人出现→温暖（家庭类）

## 场景价值判断示例

**问题场景**：张景辰去市场买菜（猪肉→鱼→橘子→讲价→回来）

**问自己**：这个场景让观众感受到什么？
- 答：买东西过程 → 没有情绪回报 → 废笔

**正确写法**：
```
△张景辰推门进来，车后座绑得满满当当——肉、鱼、橘子。
于兰（愣住）：你…买这么多？
张景辰：你爱吃嘛。
△于兰看着那堆东西，没说话，眼眶红了，赶紧低头假装整理围裙。
```
- 结果展示（车后座绑满）+ 情感反应（愣住、眼眶红）= 4行完成

**另一个例子**：追狍子

**问自己**：这个场景让观众感受到什么？
- 答：他想打猎但追不上 → 为后面搞枪做铺垫 → 有用，但节奏太慢

**正确写法**：
```
△他猫下腰捡起树枝悄悄靠近。刚抡起来，那狍子"呦"一声灵巧跳开，几下跑没了影。
张景辰OS：徒手不行…得搞把枪。
```
- 砍掉"一步一步靠近→三米两米→猛扑→扑进雪里"的慢镜头 → 2行搞定

## 节奏压缩技巧

**原则**：用最少的行数传递最大的信息量。

**技巧**：
1. **跳过过程，直接展示结果**：买东西→他推门进来车后座绑满
2. **合并场景**：买菜+做饭+吃饭 = 一个场景（他推门进来+于兰被感动）
3. **用OS替代描写**：不用写他心里想什么，用一句OS搞定
4. **砍掉过渡**：不用写"他走到门口""他推开门"，直接写结果
5. **合并对话**：把多句废话合并成一句关键台词

**例子**：原来103行的第3集，压缩到37行
- 买菜过程（18行）→ 1行结果展示
- 做饭细节（22行）→ 砍掉
- 追狍子慢镜头（40行）→ 10行核心爽点

## 感情张力体系（凡有感情线的剧本必用）

感情线不是"他们在一起了"的过程，而是**让你以为他们要在一起了但下一秒又摔碎**的反复。

### 五个必备张力节点（每段感情线至少覆盖3个）

| 节点 | 定义 | 示例 |
|------|------|------|
| 近在咫尺的错过 | 两人即将坦诚/拥抱/亲吻，被外部事件打断 | 她伸手想碰他的脸，门突然被推开 |
| 刺探式试探 | 用玩笑/假设/第三人称试探对方的真实想法 | "假若有一人，骗了你很久...你待如何？" |
| 占有欲露出 | 一方对另一方产生不该有的独占反应，却立刻掩饰 | 见他和别人说话，杯子捏紧了，脸上笑笑 |
| 身份/秘密隔阂 | 一方瞒着重要真相，每次对话都在暴露边缘 | 他问"你到底是谁"，她沉默，只说是大夫 |
| 被迫站队 | 感情与利益冲突，角色必须二选一 | "你选他，还是选你的江山？" |

### 张力节奏铁律
- **推拉周期**：每隔2-3集一次"接近→推开"，不可连续多集甜蜜或连续多集冷战
- **单集内**：感情线必须在**接近（甜）→ 变故（虐）→ 新的距离（悬）**中至少走完一轮
- **冷热交替**：一集甜不能全甜——甜后必有隐忧。一集虐不能全虐——虐后必有一丝温暖（一个眼神、一个未送出的东西）
- **禁止"说完就完"**：感情冲突不能在一场对话中解决。吵完架必须留一个未说完的话、一个未送出的东西、一个未解释的眼神

### 感情线写作检查
- [ ] 本集有没有让观众"啊！快看啊！"的错过/差点被发现/差点说出来？
- [ ] 有没有让观众"磕到了"的小动作？（帮她捻掉肩上头发、下意识挡在她身前、为她倒茶时多放了两颗糖）
- [ ] 吵完架后有没有留一根刺？（不是"误会解开了和好"，是"误会似乎解开了但好像还有一根刺"）

## 世界观可见性规则（凡有世界观改编的剧本必用）

改编后世界不是只在角色设定卡里说说——必须**让观众看到、听到、感受到**。

### 世界观四个落地层次

| 层次 | 怎么落地 | 反面例子 |
|------|----------|----------|
| 视觉层 | 服装/建筑/器物/人的站位/空间关系 | 换了身份但场景和原小说没区别 |
| 规则层 | 社会规则通过角色行为展示，不是旁白解释 | "男儿不得入仕"写在设定里，但角色从未因此被拦 |
| 冲突层 | 世界观制造的具体困境——角色因规则受伤/被阻 | 世界换了但所有冲突都和人设无关 |
| 细节层 | 每场戏至少1个世界观细节——称谓/礼仪/物价/习俗 | 所有对话和行为可以原封不动放回原小说 |

### 铁律
- 每集至少**2个视觉层细节**（服装/建筑/器物/站位）
- 每集至少**1次规则层碰撞**（社会的规则碰到了角色的行动）
- 第一个场景就要让观众看出"这不是原著的世界"——不能到第3集才出现世界观元素

### 细节清单（根据改编方向自选）
- 称谓（"郎君"vs"娘子"、谁对谁行礼）
- 服饰（谁穿什么、谁不能穿什么、颜色/材质的阶级含义）
- 空间秩序（谁站谁坐、谁先走谁跟、门内门外）
- 社会禁忌（什么不能说、什么不能做、做了会怎样）
- 经济规则（什么值钱、谁能挣钱、钱怎么花才体面）

## 单集感情曲线（每集强制）

每集必须有独立的微弧，不是平铺直叙。

```
情绪强度  ▲
          │      ╭─ peak（回报性场景展开）
          │    ╱
          │  ╱
          │╱ build（铺垫累积）
          │
          └────────────▶ 时间
          hook → → → cliffhanger
```

### 三类标准曲线（至少有一条主线贯穿全集）

| 曲线类型 | 适用场景 | build | peak | release |
|----------|----------|-------|------|---------|
| 真相渐进型 | 悬疑/查案/秘密暴露 | 蛛丝马迹累积 | 一个关键信息被揭开 | 更大的问题浮现 |
| 情绪过山车型 | 感情冲突/身份暴露 | 关系紧张/试探 | 情绪爆发（吵/哭/表白） | 一方离去/沉默/新的距离 |
| 爽点堆积型 | 复仇/打脸/逆袭 | 反派步步紧逼 | 主角反转碾压 | 反派的震惊+主角的冷酷 |

### 铁律
- build阶段必须≥2个"小事件"累积，不能一个事件就跳到peak
- peak必须是回报性场景（展开写），不能压缩成一句对话
- release不能是"圆满解决"——必须留新的悬念或未完成的情感

## 钩子强度标准（每集集末强制）

"集末必须有钩子"不够具体。钩子必须符合以下强度等级：

### 钩子强度等级

| 等级 | 类型 | 定义 | 示例 |
|------|------|------|------|
| ⭐⭐⭐ | 信息炸弹 | 揭示一个颠覆性的新信息 | 她打开盒子，里面是灭谷夜的刺客令牌 |
| ⭐⭐⭐ | 命运转折 | 角色做出不可逆的重大决定 | "我跟你走——从现在起，我不再是皇帝" |
| ⭐⭐ | 悬崖悬念 | 角色陷入即刻危险，观众不知道结果 | 刀光落下，画面黑 |
| ⭐⭐ | 关系破裂/建立 | 两个人的关系发生质变 | 他松开手："所以从头到尾，你都在骗我" |
| ⭐ | 未来承诺 | 暗示下一集有重大事件 | "明天太庙祭祖，一切都会结束" |

### 铁律
- 每集钩子必须≥⭐⭐（未来承诺不算合格钩子）
- 付费集（卡点集）的钩子必须≥⭐⭐⭐
- 钩子不能是"想知道后来怎样请看下集"——必须是一个**具体的事件或信息**让观众必须看下集
- 非末集钩子必须**在下一集开头3秒内回收**（不吊观众超过一集）
