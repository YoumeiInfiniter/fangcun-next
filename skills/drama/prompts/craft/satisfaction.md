# 爽点 Satisfaction

> 专业技能 · 适时加载 · 使用后向编剧汇报

## 什么时候用

- 观众需要"出一口气"时
- 之前的打压/虐积累到了临界点
- 付费集必含 ≥1 个爽点
- 关键身份暴露/公开打脸/逆袭时刻

## 爽点公式

爽点 = **装**（反派/对手的得意或压迫） + **打脸**（主角用硬实力/事实碾压） + **震惊**（旁观者的反应放大冲击力） + **收获**（主角得到了什么——尊严/资源/地位/情感）

## 五种爽点类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 身份暴露爽 | 隐藏身份公开，碾压轻视者 | 所有人跪下："参见陛下。"——那个骂了她三集的人脸白了 |
| 实力碾压爽 | 做不到的事做到了 | 所有大夫摇头，她一针下去，病人咳出了黑血 |
| 真相大白爽 | 被冤枉被误解，终于有人说出真相 | "不是你害死的——是赵王。我有证据。" |
| 以牙还牙爽 | 用对方的方式击败对方 | "你不是说没有证据吗？——这是你亲手写的调令。" |
| 得偿所愿爽 | 苦苦追求的东西终于拿到 | 三天三夜不眠，那道丹方终于在黎明前成了一锅 |

## 铁律

1. 爽点必须有**铺垫**——没有前面的压，就没有现在的爽
2. 爽点的核心是**旁观者反应**——一个人的震惊不如一群人的沉默有力量
3. 爽完不能"圆满结束"——爽后必须有新的问题或更大的挑战（否则观众觉得"结束了"，不会往下看）
4. 同一集爽点 ≤2 个（太多 = 观众麻木）
5. 爽不能靠"巧合"——主角赢要靠自己的选择和能力，不能靠运气

## 典型错误

| ❌ 错 | ✅ 对 |
|------|------|
| 靠巧合/天降神兵解决问题 | 问题的解决线索在前面已经埋了 2-3 集 |
| 爽完立刻结束（没有新悬念） | 爽完后抛出一个更大的危机/选择 |
| 爽的是配角（观众不在乎） | 爽的是观众投入了感情的主角 |
