# 反转 Reversal

> 专业技能 · 适时加载 · 使用后向编剧汇报

## 什么时候用

- 观众以为自己懂了，但事实不是这样
- 角色身份/动机/阵营突然翻转
- 关键信息以出乎意料的方式被揭露
- 关键集（前3集、付费集、高潮集）必含 ≥1 个反转

## 反转公式

反转 = 铺垫（让观众建立错误预期） + 揭示（用一个细节推翻预期） + 后果（反转改变了什么）

## 六种常见反转

| 类型 | 定义 | 示例 |
|------|------|------|
| 身份反转 | 角色真实身份曝光 | 她不是医女，她是女帝 |
| 动机反转 | 表面动机被推翻 | 他说帮你是为了接近你父亲 |
| 信息反转 | 以为知道的事被证明是假的 | 遗诏是伪造的，真遗诏在他手里 |
| 立场反转 | 以为的敌人其实是朋友/反之 | 追杀你三年的人，是你父亲派来保护你的 |
| 认知反转 | 角色对世界的理解崩塌 | 你引以为傲的医术——救不了你最想救的人 |
| 权力反转 | 高位者失势/低位者逆袭 | 昨日阶下囚，今日摄政王 |

## 铁律

1. 反转前必须有**铺垫**——观众回头看会发现线索一直在，但当时没注意
2. 铺垫不能太明显（观众猜到了 = 反转失败），也不能太隐晦（观众觉得突兀）
3. 铺垫方式：物品（玉佩/信件/疤痕）、对话双关（"我是来找人的"——找仇人还是找爱人？）、细节反差（他从不喝酒，但今天连灌三杯）
4. 单集反转 ≤2 个（太多 = 观众麻木）
5. 关键反转**必须通过画面揭示**，不能靠台词或旁白讲出来

## 典型错误

| ❌ 错 | ✅ 对 |
|------|------|
| 突然冒出的双胞胎兄弟 | 一集前闪过一张照片，里面有两个小孩 |
| 角色旁白说"其实我是..." | 镜头推到他的手——虎口的疤，和她父亲刀伤的疤一模一样 |
| 每集都来一个反转（贬值） | 3-4集积累铺垫 → 第5集一个大的 |
