# 扩写 Expand

> 专业技能 · 适时加载 · 使用后向编剧汇报

## 什么时候用

- 剧情关键节点需要充分展开情绪层次
- 回报性场景（反转/揭露/告白/冲突高潮）——不能一笔带过
- 短剧改编中原文一句话带过但情绪价值很高的事件
- 感情关系的关键转折点

## 扩写公式

扩写 = **识别值得展开的瞬间** + **拆解情绪层次** + **逐层展开每个层次的反应**

不需要扩写的问自己："删了这个场景，观众会觉得错过了什么吗？" 不会 = 不需要扩写。

## 情绪层次展开法

每一个值得展开的瞬间，至少包含：

**震惊 → 否认 → 确认 → 情绪爆发 → 新认知**

例：她发现自己一直在被欺骗——

| 层 | 怎么写 | 长度 |
|----|--------|------|
| 震惊 | 手一松，杯子摔了。她没低头看，只是盯着他 | 1 行 |
| 否认 | "你再说一次。"——希望他收回，希望他笑一下说开玩笑的 | 2 行 |
| 确认 | 他重复了。一字不差。她听进去了每一个字，但大脑拒绝处理 | 2 行 |
| 爆发 | 她笑了。不是开心的笑，是"我信了你三年"的笑 | 3 行 |
| 新认知 | 她没有摔门而去。她放下碎杯子，说"我帮你。最后一件事。"——观众知道她在计划复仇 | 2 行 |

## 铁律

1. 扩写的回报性场景，一集不超过 2 个
2. 每个情绪层次不能跳过——不能直接从震惊跳到复仇（观众跟不上）
3. 层次之间用**角色的身体反应**过渡（手抖/眼眶红/沉默/站不住），不要用旁白解释
4. 展开的不是"废话"，是**观众想看到但不好意思承认自己想看的情绪煎熬**

## 典型错误

| ❌ 错 | ✅ 对 |
|------|------|
| 角色旁白解释心情 | 用身体反应和动作展示心情 |
| 每个吵架都展开 5 层 → 观众累 | 只对全剧 ≤3 个关键情感节点做完整展开 |
| 展开的是"他怎么打听到消息的过程" | 展开的是"他打听到消息后的情感冲击" |
