Fangcun Novel-to-Drama Skill

小说转短剧剧本 Skill：面向多 Agent 平台的自动化改编工作流

这套 Skill 用于把长篇小说内容转化为短剧项目资产，覆盖原文读取、事件提取、短剧骨架、改编策略、分集剧本、质量审核、草稿确认和正式导出。它的定位是一个可复用的内容生产流程，而不是单次提示词写作。

一句话定位

它解决什么问题

长篇小说改短剧需要先理解原文，再重新组织主线、人物、冲突、爽点、付费卡点和分集节奏。这个过程如果只靠单轮 AI 改写，容易遗漏上下文、结构松散、剧本格式不统一。该 Skill 把改编拆成多个明确阶段，让每一步都有输入、输出和审核。

它适合什么场景

适合小说 IP 初筛、短剧项目开发、批量剧本草稿生产、编剧辅助改编、短剧投流内容前期规划，也适合在 OpenClaw、Claude Code、Codex 等 Agent 环境中作为通用型 Skill 复用。

核心能力

原文理解

章节读取与事件提取

读取小说章节，提取关键剧情事件、人物行动、冲突变化和情绪节点，为后续改编建立结构化素材。

结构规划

短剧骨架生成

将小说内容重组为短剧结构，包括集数规划、主线推进、人物关系、关键反转和阶段性看点。

商业改编

改编策略制定

明确短剧风格、目标平台、爽点强化、付费卡点、节奏压缩和人物强化方向。

剧本生产

分集剧本写作

按集生成标准剧本草稿，包含场景标题、人物、动作描述和台词，适配短剧生产格式。

质量控制

AI 审核与修订

对骨架、改编策略和分集剧本进行审核，识别严重问题、连续性问题、格式问题和可优化项。

交付管理

草稿确认与正式导出

剧本先作为草稿输出，经过编剧确认后再进入正式 scripts 目录，便于项目过程管理和版本沉淀。

完整工作流

1

输入小说

准备章节文本、项目信息、目标集数和平台风格。

2

事件分析

抽取原文关键事件，形成后续改编素材库。

3

短剧骨架

规划主线、人物、集数、冲突、反转和卡点。

4

改编策略

确定短剧化方向和商业表达重点。

5

分集剧本

逐集生成剧本草稿，并带入上下文保持连续。

6

审核导出

完成质量检查、编剧确认和正式剧本导出。

主要输出物

Skill 的每个阶段都会沉淀可查看、可复用、可追溯的项目文件，方便编剧、责编和项目负责人协同。

events.json / 事件表 记录小说原文中的关键剧情事件，是短剧重组的基础素材。
story_skeleton.md / 短剧骨架 包含故事核心、人物设定、分集规划、主线推进和关键卡点。
adaptation_strategy.md / 改编策略 说明如何把小说转成短剧，包括风格、节奏、爽点和商业化设计。
drafts/ / 剧本草稿 分批保存生成的分集剧本草稿、审核报告和修订记录。
scripts/ / 正式剧本 编剧确认后的正式分集剧本，可用于后续合稿、排版或制片流转。
reviews/ / 审核结果 保存骨架、策略、剧本等阶段的质量检查结果和修改建议。

质量控制机制

阶段审核

骨架、改编策略和剧本阶段都可以进行质量检查，避免错误进入下一环节。

连续性管理

分集剧本生成时带入前文上下文，减少人物关系、剧情线索和情绪推进断裂。

严重问题阻塞

当出现严重问题时，流程会暂停当前集，优先修复后再继续后续内容。

人工确认

AI 生成内容先进入草稿区，编剧确认后才进入正式剧本区。

适配与运行方式

多平台 Skill

该 Skill 以通用文件、命令和提示词组织能力为核心，不绑定单一 Agent 平台。当前重点使用场景是 OpenClaw，同时也可在支持本地文件和命令执行的 Agent 环境中复用。

可配置项目参数

支持配置小说名、剧名、章节目录、输出目录、目标集数、单集时长、平台风格、API 模型和分批输出数量，便于不同项目复用同一套流程。

典型使用方式

从小说到剧本的项目节奏

  • 先导入小说章节，并配置短剧项目目标。
  • 运行事件提取，形成原文素材库。
  • 生成短剧骨架，确认主线、人物、集数和卡点。
  • 生成改编策略，确认短剧化方向和商业卖点。
  • 分批生成剧本草稿，编剧审核后确认进入正式剧本。
  • 最终导出完整剧本资产，用于后续制作流程。
核心思路：让 AI 承担素材整理、结构生成和草稿生产，让编剧在关键节点做判断和确认，形成可控、可复用、可追溯的短剧改编流水线。
